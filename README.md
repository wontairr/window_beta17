# window_beta17
## A Garry's Mod map set in an apartment amidst the City 17 of the Half-Life 2 Beta

[Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3405412305)

These are the VMFs (editable map files via hammer/hammer++) for my map I made for the Hammer Editor Discord Group (HEDG) "What's Outside the Window" contest. I wasn't able to finish it properly in time, but afterwards I tidied it up and finalized it.

The final version is called "window_beta17_final.vmf", the rest are versions prior to that.

A noteable version is "window_beta17_rushed_final.vmf" where the apartment is finished and most of the buildings are finished in playable space instead of the 3d skybox.

VVV
These maps use custom textures! Use gmpublisher to download the workshop version, most assets are available on the surface, but some are still packed into the map, so use VIDE (Valve Integrated Development Environment) to extract the leftovers from the .bsp file using the Pakfile Lump Editor. (sorry for this convoluted method)

NOTE: ALL CREDIT FOR TEXTURES/MODELS GO TO VALVE, I only made the trash can, trash bag, plate, and window models.
